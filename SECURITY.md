# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting:
<https://github.com/Guigouu/dgeo/security/advisories/new>.

You can expect an acknowledgement within a few days. This is a hobby proof of concept maintained on a
best-effort basis; there is no bug bounty.

## Scope

- Vulnerabilities in dgeo's code, the Docker image or the CI configuration.
- Ways the tool could leak user data (recordings, positions, session files) beyond what is documented.

## Out of scope

- The fact that aircraft noise reveals a recording's location: that is the documented subject of the
  project. If you believe the tool is being misused against someone, contact the platform where it
  happened or the relevant authorities.
